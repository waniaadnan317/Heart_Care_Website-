# ❤️ Heart Care Website – AI Based Heart Care System

## 📌 Project Overview

Heart Care Website is an AI-based healthcare web application designed to provide heart-related medical information, assist users in understanding heart diseases, and help identify the possibility of heart disease through a prediction system.

The website includes an AI-powered medical chatbot, a heart disease prediction system, and a heart-related medical dataset to provide relevant healthcare information.

The main goal of this project is to spread heart health awareness and make heart-related medical information easily accessible to users.

## ✨ Features

### 1. AI-Powered Medical Chatbot
- Answers users' questions about heart-related diseases.
- Provides heart health information.
- Gives information about symptoms, causes, prevention, and treatments.
- Uses a heart-related medical question-answer dataset.
- Retrieves relevant answers to users' questions.

### 2. Heart Disease Prediction System
- Predicts the possibility of heart disease.
- Accepts patient-related health information.
- Analyzes entered health parameters.
- Displays prediction results.
- Helps identify potential heart disease risks.

### 3. Heart-Related Medical Dataset
- Integrated medical question-answer dataset.
- Contains information related to heart diseases.
- Provides relevant medical information for chatbot responses.
- Focuses only on heart-related diseases and heart health.

### 4. Heart Disease Information
- Provides information about different heart diseases.
- Explains common symptoms and causes.
- Provides information about prevention and treatment.
- Promotes awareness about cardiovascular health.

### 5. Heart Health Awareness
- Provides educational heart health information.
- Encourages healthy lifestyle habits.
- Helps users understand the importance of heart health.

### 6. Database Integration
- Uses SQLite database.
- Stores relevant application data.
- Database file: `hospital.db`.
